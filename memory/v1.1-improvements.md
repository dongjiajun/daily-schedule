v1.1 版本改进已推送 origin/main。

**P0 Bug 修复**
- 标签名/颜色不返回前端（EventAssembler.toResponse）
- @Valid 校验启用，GlobalExceptionHandler 加日志 + 修正 RuntimeException→500
- 前端 ErrorBoundary + sonner Toast 操作反馈

**P1 核心增强**
- 搜索: keyword 参数支持 LIKE 全文搜索（标题/描述/地点）
- 分页: page/size 参数 + total 计数 + EventMapper 动态 SQL
- N+1 优化: saveTags 批量 INSERT，标签通过 JOIN 批量加载
- 缓存: Caffeine 缓存分类/标签，Spring Cache 注解
- 拖拽: 已实现在 CalendarView 但 react-big-calendar DnD 有 CJS/ESM 兼容问题，暂禁用

**P2 架构变更**
- 多用户: User 实体 + Spring Security + JWT + 所有表 user_id 隔离
- Docker: Dockerfile × 2 + docker-compose.yml + nginx 反向代理
- SSE 重连: 指数退避自动重连

**P3 体验打磨**
- Framer Motion 弹窗动画 + 骨架屏加载 + 键盘快捷键 (n 新建, Esc 关闭)
- 视觉升级：渐变背景、卡片阴影分层、胶囊工具栏、品牌色点缀
- 预设分类：新用户注册自动创建 6 个默认分类
- 引导教程：首次登录 3 步引导（Framer Motion + localStorage）
- 日历重设计：月视图卡片悬浮（天格子圆角+间隙）、今日内阴影、周视图卡片化头部、当前时间线红点
- 引导教程可重新进入：侧边栏底部「使用指南」按钮
- 登录页动效：6 色渐变光斑、卡片入场动画、按钮渐变
- 分类管理：侧边栏「分类」旁 + 按钮 → 内联表单（名称+9 色盘）创建分类

**测试**
- 81 用例全部通过（11 个测试类）
- CI: H2 内存数据库，无需 MySQL
- 后端: `mvn test`，前端: `npm run lint && npm run build`

**本地运行**
- 后端: `mvn spring-boot:run -DskipTests -Dmaven.test.skip=true`（端口 8080）
- 前端: `npx vite --host`（端口 5173）
- 登录: admin / admin123
